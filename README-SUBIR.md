# SUBIR-A-GIT-CHICO

Version preparada para subir por tandas chicas a GitHub web.

Incluye:
- index.html
- PDFs chicos en la raiz
- PDFs grandes divididos en programas-divididos/<programa>/
- imagenes-premium separadas por idioma
- testimonios

Subida recomendada:
1. Subir primero index.html, README y PDFs chicos de la raiz.
2. Subir programas-divididos por carpeta.
3. Subir imagenes-premium idioma por idioma.
4. Subir testimonios.

Los PDFs grandes fueron divididos porque GitHub web suele fallar con archivos grandes.
